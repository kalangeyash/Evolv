# Changelog

## 1.0.0 — 2026-11-25

First release of EVOLV.

- Static Next.js 16 app, deployable to GitHub Pages, with an installable PWA and offline support.
- IndexedDB storage (Dexie) with a versioned schema, seed profile and targets, provenance on every record.
- Gemini daily report import: tolerant deterministic parser, editable preview, totals reconciliation, duplicate detection with merge/replace, transactional save, import history with original text.
- Overview with intake-through-the-day chart, nutrition targets, activity rings, weight summary, meal timeline, data-driven observations, and customisable widgets.
- Food Journal (day view by meal, search and filters, frequent foods, meal analytics), with correction tracking.
- Nutrition analytics (daily, weekly, monthly; protein, fiber and calorie intelligence; macro distribution).
- Activity analytics from Apple Watch data, with manual entry and correction.
- Workouts: strength and cardio logging, exercise library, personal records, Epley 1RM estimates, volume, frequency, muscle-group distribution.
- Body analytics: weight with 7-day moving average and weekly/monthly averages, measurements, BMI with caveats.
- Progress: recomposition indicators, insights with evidence, energy balance with confidence labels.
- Calendar heatmap, printable weekly/monthly reports, versioned goals with a macro consistency check.
- Data management: JSON backup and validated atomic restore, CSV exports, erase-all, backup reminders.
